# 快速上手

全程只需要复制提示词，不需要装环境、不需要密钥。脚本是可选进阶。

## 流程总览

```
选题 → 写稿 → 排版 → 存草稿 → 人工点发布
01     02     03      04        你
```

四步各有对应的提示词文件，前一步的输出就是后一步的输入。

## 第 1 步：选题

1. 打开 `prompts/01-topic/topic-research.md`，把里面的提示词复制到你的 AI 工具。
2. 填上你的账号定位和你关心的方向，让它产出一批候选主题。
3. 如果担心和已发内容重复，再用 `topic-dedup.md`，把历史文章清单贴进去做查重。
4. 从候选里挑一个，作为第 2 步的主题。

> 这一步完全不挑领域。账号是做什么的，就填什么方向。

## 第 2 步：写稿

1. 打开 `prompts/02-writing/article-draft.md`，把第 1 步选出的主题填进去。
2. 得到初稿后，用 `title-variants.md` 生成几个标题备选。
3. 再用 `de-ai-polish.md` 过一遍，去掉 AI 腔。
4. 人工核对：文中所有事实、数据、引用是否准确。AI 会提醒你核对，但不会替你负责。

## 第 3 步：排版

1. 打开 `prompts/03-layout/wechat-html.md`，让 AI 把正文转成带排版的版本。
2. 字号、配色、间距参数在 `style-vars.md`，可按你的账号风格调整。

## 第 4 步：存草稿

两条路，二选一：

- **手动（推荐所有新手）：** 把排版好的内容复制进公众号后台编辑器，存草稿。不需要任何配置。
- **脚本（进阶）：** 想省掉复制粘贴，用 `scripts/push_draft.py`。脚本已经把标题字数、正文图片、封面格式、token 缓存这些坑都处理好了，照着 `examples/article-html-example.md` 跑即可。前提是先配好 `.env` 并跑 `scripts/check_env.py` 自检。

草稿箱接口的权限结论和完整配置步骤见 `docs/wechat-api.md`。

## 最后一步

去公众号草稿箱检查排版和封面，确认无误，**自己点发布**。本流程没有任何自动群发能力。
