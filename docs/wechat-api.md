# 公众号草稿箱接口说明

这一步是整套流程里唯一和具体平台绑定的环节。其余三步（选题、写稿、排版）都是纯文本，换个平台照样能用。

本章目标：**第一次用就能一次成功，不用自己装东西、调参数、猜报错。**

## 先给结论：个人号能存草稿，这是官方明确的

微信官方文档把"存草稿"和"群发发布"分成了两个接口，权限完全不同：

| 接口 | 作用 | 个人号 / 未认证号 |
|---|---|---|
| `draft/add` 新增草稿 | 把文章放进草稿箱 | ✅ 官方标注公众号可调用，无认证要求 |
| `freepublish/submit` 发布 | 群发出去 | ❌ 2025 年 7 月起个人主体、未认证企业主体被回收 |

**所以个人号跑这套流程没问题——存草稿的接口一直开着，被收走的是群发接口。** 网上那些"个人号报 48001"的说法，多半是把这两个接口搞混了。本项目也完全不碰群发接口，最后一步永远由你在后台手动点发布。

来源（2026-11 核对，以官方最新文档为准）：

- 新增草稿 `draft/add`：`https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_add`
- 发布 `freepublish/submit`：`https://developers.weixin.qq.com/doc/service/api/public/api_freepublish_submit`
- 上传正文内图片 `media/uploadimg`：`https://developers.weixin.qq.com/doc/service/api/material/permanent/api_uploadimage.html`

## 小白一次成功的完整步骤

### 准备（只做一次，约 10 分钟）

1. **装 Python 3。** Mac 和多数新 Windows 自带；终端输 `python3 --version` 有版本号就行。没有就去 python.org 下载安装，一路默认。
2. **拿密钥。** 打开 `developers.weixin.qq.com` → 用公众号管理员微信扫码登录 → 我的业务 → 公众号 → 基础信息。
   - AppID 直接复制。
   - AppSecret 点"重置"、管理员扫码后显示，**只显示这一次，当场复制**。
   - 注意：2025 年 12 月起这个入口已从旧后台的"基本配置"页挪走，在旧后台找不到是正常的。
3. **配 IP 白名单。** 公众平台 → 设置与开发 → 基本配置 → IP 白名单，把当前公网 IP 加进去。双栈网络 IPv4 和 IPv6 都要加，只加一个会随机失败。家庭宽带 IP 会变，变了就更新。
   - 查当前公网 IP：浏览器搜"我的 IP"。
4. **填配置。** 把 `.env.example` 复制成 `.env`，填入 `WECHAT_APPID` 和 `WECHAT_SECRET` 两个值，保存。这个文件不会上传 GitHub。

### 每次使用

```bash
# 1. 自检（第一次必跑，之后可跳过）
python scripts/check_env.py
# 三项全绿再往下走。任何一项红了，报错信息里已经写了怎么修。

# 2. 推草稿
python scripts/push_draft.py \
  --html output/article.html \
  --cover output/cover.jpg \
  --title "你的标题"
```

### 脚本帮你处理好的坑（不用你操心）

| 坑 | 脚本怎么处理 |
|---|---|
| 标题超字数被拒 | 建草稿前拦下，提示"超过 32 字" |
| 正文里放图片不显示 | 本地图自动上传换成微信域名；外链图会提醒你换 |
| 封面格式不对 | 自动识别 jpg / png |
| token 反复获取限流 | 本地缓存 2 小时，过期自动刷新 |
| 报错看不懂 | 错误码翻译成中文，直接告诉你改哪里 |

## 常见报错对照

| 报错码 | 意思 | 怎么修 |
|---|---|---|
| 40164 | IP 不在白名单 | 加当前公网 IP，IPv4 和 IPv6 都加 |
| 48001 | 接口未授权 | 草稿接口一般都有；真遇到就用手动复制 |
| 40001 | AppSecret 不对 | 去开发者平台重置，更新 .env |
| 40013 | AppID 不对 | 检查 .env 里的 WECHAT_APPID |
| 40009 | 图片太大 | 正文内图片必须小于 1MB |
| 45009 | 调用太频繁 | 等一会儿再试 |

## 手动路径（不想配 API 就用这个）

前三步产出的内容，直接复制进公众号后台编辑器，存草稿。不需要 Python、不需要密钥、不需要白名单。**这条路径永远可用**,脚本只是省事,不是必需。

## 最后一步

无论用哪条路径,草稿都要去后台打开检查排版和封面,确认无误后由你**手动点发布**。本项目没有任何自动群发能力。
