# 常见问题

## 关于流程本身

**Q：这套流程只能写某一类内容吗？**
不是。流程是通用的，主题是变量。写职场干货、影评、旅行攻略、产品测评，走的是同一条四步流水线，只换第 1 步输入的方向和风格设定。它不是公文或任何特定领域的方案。

**Q：一定要用公众号吗？**
不必。前三步（选题、写稿、排版）产出的是通用文本和 HTML，知乎、小红书、博客都能用。只有第 4 步"存草稿"是和公众号后台绑定的，也可以换成手动复制到任何平台。

## 关于写稿质量

**Q：AI 写出来的东西 AI 味重怎么办？**
用 `prompts/02-writing/de-ai-polish.md` 过一遍。核心是去掉套话、排比堆砌、机械过渡词，改成第一人称、短句、口语。

**Q：数据、事实准吗？**
不保证。提示词会要求 AI 标注不确定处，但核对责任在使用者。发布前务必自己查一遍所有数字、引用、专业判断。查不到就写"查不到"，别编。

## 关于草稿箱

**Q：我的个人号能用脚本推草稿吗？**
能。微信官方明确个人号可调用草稿接口（受限的是群发，本项目不碰）。第一次用先跑 `scripts/check_env.py` 自检，报错信息里写了怎么修，详见 `docs/wechat-api.md`。不想配 API 就走手动复制，不影响其他三步。

**Q：报 40164 / 48001 是什么意思？**
`40164` 是 IP 白名单没配对；`48001` 是接口未授权。两者原因不同，处理办法见 `docs/wechat-api.md`。

**Q：标题创建草稿失败？**
标题最长 32 个字（微信官方限制），超了会失败。用 `title-variants.md` 生成标题时注意长度，脚本也会在建草稿前拦下并提示。

**Q：草稿里图片不显示？**
微信只认自己域名的图片。用 `push_draft.py` 的话，正文里的本地图会自动上传换成合法地址；外链图片（其他网站的图）会被微信过滤，脚本会提醒你换成本地图。`examples/article-html-example.md` 有可照抄的例子。

## 关于配置

**Q：只用提示词，需要填密钥吗？**
完全不需要。密钥只在你想用 `scripts/push_draft.py` 脚本推草稿时才用得上。

**Q：.env 会被传到 GitHub 吗？**
不会。`.gitignore` 已经排除了 `.env` 和所有 `.env.*`。提交前仍建议全文搜一下 AppID / AppSecret 有没有混进别的文件。
