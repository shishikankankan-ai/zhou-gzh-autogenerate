# 完整流程说明

这套流程的核心是一个判断：**写什么主题会变，怎么把主题做成文章的流程不变。**

因此流程被拆成四个固定环节，每个环节输入主题相关的内容，输出规范的中间产物，交给下一环。

## 四环怎么串

| 环节 | 输入 | 输出 | 用的提示词 |
|---|---|---|---|
| 1 选题 | 账号定位 + 关注方向 | 一组候选主题 | topic-research / topic-dedup |
| 2 写稿 | 选定的主题 | 初稿 + 标题 + 去 AI 味后的定稿 | article-draft / title-variants / de-ai-polish |
| 3 排版 | 定稿正文 | 带 HTML 排版的成稿 | wechat-html / style-vars |
| 4 存草稿 | 成稿 | 草稿箱里的一篇草稿（或可复制的内容） | draft-checklist + 可选脚本 |
| 人工 | 草稿 | 已发布的文章 | （你） |

## 为什么这样拆

- **解耦。** 某一环不满意，只重做那一环，不用从头来。比如排版不好，只重跑第 3 步。
- **可替换。** 每一环都独立于具体 AI 工具。你今天用 A 工具选题、明天用 B 工具写稿，流程照样成立。
- **可迁移。** 换主题 = 换第 1 步的输入。写职场干货和写影评，走的是同一条流水线。

## 用在不同场景的例子

同一流程，只改主题和风格设定：

- 职场号：主题填"Excel 常用公式"，风格选"干货、可截图即用"
- 影评号：主题填"某部电影",风格选"口语、有观点"
- 行业号：主题填"某项新规解读",风格选"专业、条理清晰"

流程本身一个字都不用动。

## 人要在哪里介入

1. 第 1 步末尾：从候选里挑主题（AI 给选项，人做决定）。
2. 第 2 步末尾：核对事实、数据、引用是否真实准确。
3. 第 4 步末尾：检查排版和封面。
4. 发布：始终由人点。

流程帮你省的是重复劳动，判断和责任不转移。
