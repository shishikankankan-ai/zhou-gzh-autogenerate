# 风格设定模板

同一个主题，不同风格写出来完全不一样。把这份设定填好，粘进写稿提示词的"风格"一栏。流程不变，风格可换。

## 模板

```
目标读者：【谁会看这篇】
写作目的：【看完能解决什么问题】
语气：【例如：第一人称、口语化 / 专业、克制 / 犀利、有观点】
篇幅：【大概多少字】
要避免的：【例如：不要套话、不要煽情、不要 AI 腔】
必须包含：【例如：要举具体例子、要给出可操作步骤】
```

## 几个现成的风格样例

**干货可截图即用型**
```
目标读者：刚接触这个领域的新手
写作目的：看完就能上手操作
语气：老手带新手，用「你」不用「我们」，判断句多、形容词少，短句短段
要避免的：套话、鸡汤、正确废话
必须包含：具体步骤、可复制的示例、避坑、一句能背的口诀
```

**观点犀利型**
```
目标读者：对这个话题有一定了解的人
写作目的：给一个有立场的判断
语气：口语、冲突型/情绪型、敢下结论，短句
要避免的：和稀泥、机械过渡词、四平八稳、排比堆砌
必须包含：明确立场、支撑例子、和常见看法的不同点
```

**实战复盘型**
```
目标读者：想少走弯路的同行
写作目的：把我踩过的坑和验证过的方法交出去
语气：第一人称讲亲身经历，有数据对比，克制不自夸
要避免的：煽情、升华、正确废话
必须包含：真实场景、前后对比、错→改的避坑、可照抄的做法
```
