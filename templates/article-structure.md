# 文章结构骨架

一个通用的图文结构。任何主题都能套，套的时候只换内容不换骨架。

```
标题：【选好的标题】

【开头：直接切入，说清这篇给谁看、解决什么问题。3-5 行，不铺垫。】

## 第一部分：xxx
- 具体观点 / 方法
- 举例说明
- 注意事项

## 第二部分：xxx
- 具体观点 / 方法
- 举例说明
- 注意事项

## 第三部分：xxx（可选）
- ...

【结尾：给一个可操作的下一步，或一句朴素的总结。不煽情、不鸡汤。】

【下期预告（可选）：一句钩子，告诉读者下一篇大概讲什么。】
```

## 用法

把骨架连同 `prompts/02-writing/article-draft.md` 的提示词一起给 AI，让它按骨架填充内容。不同账号可以改骨架的小标题数量和结构，流程不变。
