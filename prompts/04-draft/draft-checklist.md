# 存草稿前检查清单

推草稿之前，逐项确认。这一步纯人工，和主题无关。

## 内容

- [ ] 标题 ≤ 32 字（公众号上限）
- [ ] 正文里所有【需核对】的标记都已处理：数据、引用、事实查证完毕
- [ ] 查不到的内容已写"未验证"或删除，没有编造
- [ ] 没有把不该公开的信息写进去（内部信息、他人隐私、真实身份等）

## 排版

- [ ] 样式是内联 style，没有 class
- [ ] 图片是微信域名，外链图已换成微信素材
- [ ] 字号、行距、配色符合你的账号风格

## 发布前

- [ ] 去草稿箱打开这篇，检查封面和排版实际效果
- [ ] 确认无误后，由你手动点发布

本流程没有任何自动群发能力。最后一步始终在人手里。
