# 提示词：历史文章查重

用途：避免选题和已发内容撞车。可选步骤。

## 复制下面这段到 AI 工具

```
下面是我已经发布过的文章清单（标题 + 一句话主题）：

【在这里粘贴你的历史文章清单，格式：标题 | 主题一句话】

我准备写的新主题是：【填新主题】

请判断：
1. 这个新主题和历史文章有没有重复或高度相似？逐个列出可能撞车的旧文章，说明相似点。
2. 如果撞车，给出 3 个可以做出差异化的新角度。
3. 如果不撞车，说明它和已有内容的区别在哪。

只做查重和找角度，不要替我写正文。
```

## 填法说明

- 历史清单可以用 `config/history.example.csv` 的格式整理，贴进来即可。
- 没有历史文章就跳过这一步。

## 下一步

确认主题不撞车后，进入 `02-writing/article-draft.md`。
