# 排版参数参考

公众号 HTML 排版的常用参数。按你的账号风格改，流程不变。

## 正文

| 项 | 建议值 | 说明 |
|---|---|---|
| 字号 | 16px | 移动端阅读舒适 |
| 行高 | 1.75 | 段落不挤 |
| 段间距 | margin-bottom 1em | 靠 margin，不用空行 |
| 字色 | #333 | 不要纯黑，刺眼 |
| 对齐 | 左对齐 | 不要两端对齐，中文会出现大空隙 |

## 小标题

| 项 | 建议值 |
|---|---|
| 字号 | 18px |
| 字重 | bold |
| 上下间距 | margin 1.5em 0 0.5em |

## 颜色

主色最多两种。全文统一，不要每段换色。配色只影响观感，不影响流程能被复用——换账号时只改这里的色值。

## 视觉块密度（决定"华丽还是发灰"）

实战校准的合格线，达不到文章就会显得单调：

| 块 | 合格线 | 说明 |
|---|---|---|
| 引用卡片 | 4–6 处，占比 8%–15% | 只放金句和判断，不放长段；太多会变花框 |
| 分割线 | 3–4 条 | 只放大节之间 |
| 列表/编号 | ≥2 组，每组 3–6 条 | 逐条列举的一定用列表 |
| 加粗 | 3 处 | 只标关键判断句 |
| 短段 | 70% 段落 ≤60 字 | 超过 80 字的长段全篇 ≤3 处 |
| 独立短句 | 每节 ≥1 处（4–12 字） | 制造节奏 |

## 技术约束

- 样式必须内联（`style="..."`），公众号会过滤 class 和外部样式表。
- 图片用微信域名；本地图片由 push_draft.py 自动上传，外链图会被微信过滤。
- 标题 ≤ 32 字（公众号标题上限）。
